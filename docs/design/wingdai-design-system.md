# Wingdai Design System — "rounded-soft"

ระบบดีไซน์ที่ใช้จริงในแอปตั้งแต่ 2026-07-27 อ้างอิงจาก design handoff (`Wingdai App.dc.html`, 58 หน้าจอ)
**ทุกหน้าจอใหม่ต้องประกอบจาก primitive ใน `apps/mobile/src/ui/` เท่านั้น ห้ามเขียนสี/รัศมี/เงาดิบในไฟล์หน้าจอ**

---

## 1. ภาษาภาพ

นุ่ม มน อบอุ่น — การ์ดมุมมนบนพื้นครีมอุ่น เงาฟุ้งบาง ๆ แถบนำทางทรงพิลลอยเหนือเนื้อหา
ปุ่มหลักย่อลงเล็กน้อยตอนกด สีส้มแบรนด์เป็นตัวนำ สีเขียว teal เป็นตัวเสริมและใช้กับจอเข้ม

### ⚠️ กฎสำคัญ — ทำไม CTA ไม่ใช่ `#F15A22` เป๊ะ

`#F15A22` คือสีส้มจริงของ design แต่ **ตัวหนังสือขาวบนสีนี้ได้ contrast แค่ 3.37:1** ซึ่งไม่ผ่าน WCAG AA
(ต้อง ≥ 4.5:1 สำหรับตัวอักษรขนาดปกติ) และตัวอักษรสีนี้บนพื้นครีมได้แค่ 3.00:1

จึงแยกเป็นสองบทบาท:

- `brandAccent` = `#F15A22` — ใช้กับ **กราฟิกที่ไม่มีตัวหนังสือทับ** (ผ่านเกณฑ์ non-text 3:1)
- `brandSolid` = `#CC4310` — เฉดเดียวกัน (hue 16°) แต่เข้มพอให้ตัวขาวผ่าน AA (4.80:1) → ใช้เป็นพื้นปุ่ม/พิล
- `brandLink` = `#B23A0C` (สี "orange pressed" ของ design เอง) → ตัวอักษรสีแบรนด์ (5.34:1 บนครีม)

เทสต์ `__tests__/theme/contrast.test.ts` ล็อกกฎนี้ไว้ **ห้ามแก้ให้ผ่านโดยลดเกณฑ์**

## 3. รูปทรง ระยะ ตัวอักษร

- **รัศมี** (`p.radius`): `sm 12` ชิปไอคอน · `md 16` อินพุต · `pill 18` ปุ่ม · `lg 20` / `xl 24` การ์ด · `full` พิล
- **ระยะ** (`p.space`): `screen 20` ขอบจอ · `card 16` ในการ์ด · `sm 8`/`md 12`/`lg 16` ช่องไฟ
- **เงา** (`p.shadow`): `card` การ์ดทั่วไป · `raised` การ์ดเด่น · `brand` ปุ่มหลัก · `teal` พื้นผิว teal ลอย
- **ตัวอักษร**: หัวข้อ `Prompt_700Bold` · เนื้อความ `IBMPlexSansThai_400Regular` / `_600SemiBold` (prop `bold`)
  - variant: `kicker 11` (letterSpacing 1.4) · `caption 13` · `small 14` · `body 16` · `bodyLg 18` · `h3 20` · `h2 24` · `h1 28` · `display 32`
  - **lineHeight ต้อง ≥ 1.7× ของ fontSize เสมอ** ไม่งั้นสระไทยชนกัน (มีเทสต์ล็อกไว้)
  - `allowFontScaling={false}` ตั้งไว้ที่ `ui/Text.tsx` ที่เดียว

design ใช้ body 13–14px แต่เราขยับขึ้นเพราะภาษาไทยอ่านยากกว่าอังกฤษที่ขนาดเท่ากัน

## 4. คลัง component (`src/ui/`)

| ไฟล์ | ให้อะไร |
|---|---|
| `Text.tsx` | `<Text variant color bold>` — ทางเดียวที่ควรแสดงตัวอักษร |
| `Button.tsx` | `primary` / `secondary` / `teal` / `ghostOnDark` · สูง 56 · `trailingLabel` สำหรับยอดรวมชิดขวา |
| `Surface.tsx` | `Card` `IconChip` `RoundButton` `Chip` `Badge` `Toggle` `PhotoBlock` |
| `Field.tsx` | `Input` (wd-in: ขาว มุม 16 เงานุ่ม ขอบส้มตอนโฟกัส) · `Field` (ป้าย kicker + ช่อง) |
| `ScreenHeader.tsx` | ปุ่มย้อนกลับสี่เหลี่ยมมน 40px + ชื่อจอ |
| `Icon.tsx` | ไอคอนเส้น Lucide-compatible (registry ชื่อ → path) |

`PhotoBlock` คือบล็อกแทนรูปอาหาร (ไล่เฉดเทา) — เปลี่ยนเป็นรูปจริงได้ที่จุดเดียวโดยไม่ต้องแก้หน้าจอ

## 5. แถบนำทาง

`src/app/navigators/WingdaiTabBar.tsx` — พิล teal ลอย มุม 24 เงานุ่ม
แท็บที่เลือกมีแผ่นส้มมนรองไอคอน · ปุ่มตะกร้าวงกลมกลางแถบ (ตะกร้าอยู่บน stack แม่ ไม่ใช่แท็บ) พร้อมตัวนับ

จอที่อยู่ในแท็บต้องเว้นล่าง `TAB_BAR_CLEARANCE` ไม่งั้นเนื้อหาโดนแถบทับ

navigator ทุกตัวปิด `headerShown` — **แต่ละหน้าวาดหัวจอเองด้วย `ScreenHeader`** ตาม design

## 6. สิ่งที่ *ไม่* เอามาจาก design handoff

handoff มี 58 จอครอบคลุมฟีเจอร์ที่ `CLAUDE.md §2` สั่งห้ามสร้างใน Phase 1 — เอามาแค่ **ภาษาภาพ** ไม่เอาฟีเจอร์:

- ❌ Deals/โปรโมชัน/ช่องกรอกโค้ดส่วนลด (C16, C17 discount line, M8) — ขัด §3 ข้อ 3
- ❌ Group order (C23) · Wallet/แต้ม (C22) · บัตรเครดิต/TrueMoney/เงินสด (C18) — ยังไม่ถึงเฟส
- ❌ ตัวนับถอยหลังบนจอ PromptPay — ยังไม่มี expiry จริง จะเป็น UI หลอก
- ❌ ช่องค้นหา (C2) · ที่อยู่จัดส่ง (C9) — ยังไม่มีฟีเจอร์รองรับ ใส่ไปจะเป็นปุ่มตาย

**หลักการ: ห้ามใส่ UI ที่กดแล้วไม่มีอะไรเกิดขึ้น** ถ้า design มีองค์ประกอบที่ระบบยังไม่รองรับ ให้ตัดออกก่อน แล้วค่อยใส่ตอนทำฟีเจอร์นั้นจริง

## 7. เช็กลิสต์ก่อนส่งหน้าจอใหม่

1. สีทุกจุดมาจาก `tokens.*` — ไม่มี hex ดิบในไฟล์หน้าจอ (ยกเว้นสีบนพื้น teal ตายตัว)
2. ตัวอักษรผ่าน `ui/Text` ทั้งหมด
3. พื้นที่แตะ ≥ 44px
4. ตรวจทั้งโหมดสว่างและมืด
5. `npx jest` เขียว + `npx tsc --noEmit` สะอาด (รันจาก `apps/mobile`)
